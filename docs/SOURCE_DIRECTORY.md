# Washington Rep Permit / Prospecting Source Directory

Use **planning/development sources for early leads** and **issued building permits to confirm construction is moving**.

| Market | Rep source | Best use |
|---|---|---|
| Seattle | https://data.seattle.gov/Permitting/Building-Permits/76t5-zqzr | City open-data permit research |
| Seattle | https://www.seattle.gov/construction-and-inspections/resources/research-a-project | Permit/site-history research, project team and documents |
| Seattle | https://web.seattle.gov/sdci/ShapingSeattle/buildings | Map-based property/building permit prospecting |
| Seattle | https://services.seattle.gov/Portal/Customization/SEATTLE/welcome.aspx | Individual permit / project lookup |
| Bellevue | https://bellevuewa.gov/development-activity | Active development, major projects, permit map and weekly bulletin |
| Bellevue | https://bellevuewa.gov/city-government/departments/development/permits | Permit search / MyBuildingPermit |
| Tacoma | https://aca-prod.accela.com/tacoma/Default.aspx | Search permit records and project status |
| Spokane | https://aca.spokanepermits.org/ | Building and planning record search |
| Clark County | https://permits.clark.wa.gov/pub/lms/Default.aspx?PosseMenuName=PC_Search | Search permits by address, number, contractor, date or project |
| Clark County | https://www2.clark.wa.gov/forms/permits/buildinghist.asp | Permit type codes and permit-history search |
| Vancouver, WA | https://cityofvancouver.myrelayview.com/Permits | City permit lookup / inspections / status |
| King County | https://aca-prod.accela.com/kingco | Unincorporated King County permit and application search |
| Pierce County | https://www.piercecountywa.gov/permit | County permit dashboard / applications |
| Snohomish County | https://www.snohomishcountywa.gov/2299/Project-Status | Current and historical permit/project search |
| Everett | https://onlinepermits.everettwa.gov/etrakit/default.aspx | Permit and project search |
| Bellingham | https://permits.cob.org/etrakit/ | Permit/project/property search |
| Olympia | https://ci-olympia-wa.smartgovcommunity.com/Public/Home | Public permit / parcel portal |
| Lacey | https://trakitweb.ci.lacey.wa.us/eTRAKiT/ | Permit portal / project lookup |
